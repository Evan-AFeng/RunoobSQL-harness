# 当前迭代任务

本文记录当前迭代的目标、范围和验收标准。

## 迭代目标

- 明确 Flask、Vue 3、SQLite 的模块边界。
- 提供最小可用的 API、错误码和测试规范。

## 当前范围

- 初始化 `backend/` 和 `frontend/` 目录结构。
- 定义后端 API 响应格式。
- 定义统一错误码。
- 建立基础单元测试入口。
- 补齐项目文档。
- 实现基础功能

## 非当前范围

- 多数据库适配。
- 生产级任务队列。
- 分布式部署。

## 验收标准

- 文档导航中的文件均存在。
- 后端新增功能有单元测试。
- 所有测试通过。
- 单文件不超过 500 行。
